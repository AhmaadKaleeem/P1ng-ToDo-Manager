# Todow

Todow is a mobile app for students to manage tasks and schedules.

## Features

### Completed
- Task management
- Roadmap management
### Ongoing
- File attachments (PDFs, images) inside tasks.

### Upcoming
- Google Calendar and Google Classroom sync.
- Focus mode with app blocking.
- Multi-device sync.
- Class timetables.

Everything is stored locally on your device.

## Setup

```bash
flutter pub get
flutter run
```

Run tests:

```bash
flutter test
flutter analyze
```
